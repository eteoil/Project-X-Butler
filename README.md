# 🌹 Project X Butler

X（旧Twitter）の運用を支援する自動化Bot。

## ✨ 主な機能

- 🔁 自動リポスト
- ❤️ 自動いいね
- 📝 ランダム投稿
- 📅 定時投稿

## 開発方針
- 1実装ごとにテストする
- 1実装ごとにGitへコミットする
- 新機能は既存システムを利用して実装する

## 🛠 Tech Stack

- Node.js
- Playwright
- Google Cloud Run
- Google Sheets
- Google Apps Script
